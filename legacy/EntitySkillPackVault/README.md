# Entity Skill Pack Knowledge Base

This is an Obsidian knowledge base for designing and developing a general-purpose Entity skill pack.

The goal is to help agents use
[Entity](https://github.com/entity-toolkit/entity) in three main ways:

- run plasma simulations reproducibly;
- analyze simulation results with nt2py and numerical diagnostics;
- develop Entity features based on the current source checkout.

## Current Status

This vault is the design and guidance layer, not yet a directly installable skill pack. The first-phase implementation goal is a minimal viable version:

- router skill;
- shared source-of-truth knowledge;
- two core skills: simulation and development;
- run/development templates.

## Writing Conventions

Notes in this Obsidian vault were originally written in Chinese. Code identifiers, commands, paths, YAML field names, and upstream English terms were kept in English.
